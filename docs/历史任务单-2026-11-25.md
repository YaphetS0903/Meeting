# 历史任务单（本地修改，2026-11-25）

“我的待办”标题下新增“当前待办／历史任务单”切换。历史入口默认开启“只看我的”，支持状态、会议日期／名称／任务内容搜索及分页。已关闭、已撤回的任务也可查阅。

历史列表合并已留存的正式任务和已发布会议中的历史条目：已有正式任务按任务身份只列一条，使用最新有效状态；未生成正式任务的历史导入条目按会议保留，展示原会议评定。多人任务在“只看我的”时按本人的评定筛选。未发布草稿不进入列表，每场会议只采用当前已发布版本。

历史详情展示内容、责任人、验证人、期限、备注和来源会议；正式任务保留已有申请、凭据下载及版本记录。历史入口仅供查阅，任务操作继续在当前业务入口办理。

后端新增只读 `GET /api/task-history`，复用既有任务与会议权限。关闭“只看我的”仍只能查询已获授权的范围；任务总览权限不会额外暴露来源会议的名称或日期。历史读取不创建任务、修改评定或发送通知，无数据库迁移。

本次仅修改本地代码。验证结果和页面截图保存在工作区 `.validation/task-history-20261125/`，最终状态以该目录 `validation.json` 为准。
